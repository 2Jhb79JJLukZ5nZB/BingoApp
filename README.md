# ビンゴボード

ビンゴで呼ばれた番号を記録する、GitHub Pages向けのシンプルなウェブアプリです。

## 機能

- Googleスライドと番号ボードを1つの画面に並べて表示
- Googleスライドの操作、アニメーション再生、全画面表示に対応
- 1〜100の番号をEnterキーまたはボタンで追加
- 呼ばれた順番を3列で表示
- 各番号の×ボタンから削除
- ブラウザー内に番号を自動保存
- PC・スマートフォンに対応

## ローカルでの確認

外部ライブラリは使用していません。`index.html`をブラウザーで開くか、任意の静的ファイルサーバーでこのフォルダーを配信してください。

`main`ブランチへプッシュすると、GitHub ActionsがGitHub Pagesへ自動公開します。
